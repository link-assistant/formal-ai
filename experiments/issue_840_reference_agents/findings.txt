WHAT THIS PROVES
----------------
Six of seven agents that actually ran found the folder, including four free
models. Two of them (claude, laguna) additionally named the name discrepancy.
Formal AI failed the same task with a single over-built command.

This is a PROCEDURE gap, not a model-capability gap. The winning procedure is
uniformly: look, then narrow — never guess a clever pattern up front. The
cheapest models beat us with two `ls` calls.

EXTRACTED STANDARD (encoded as #840 section 3)
----------------------------------------------
  1. Prefer `ls` of the named location; recurse one level at a time.
  2. One simple command per step — never chain with ';' (contrast ling).
  3. On an empty result, BROADEN and retry before reporting absence (codex, laguna).
  4. Fuzzy-match and NAME the discrepancy (claude, laguna).
  5. Never `-print -quit`: it hides better matches.
  6. Distinguish file vs folder when the user asked for a folder.
  7. Absence claims must state the scope actually searched.
