## Issue #674 Arbitrary Natural-Language Programs

Issue [#674](https://github.com/link-assistant/formal-ai/issues/674) (E55) closes
the `ARCHITECTURE.md` §16 question carried since the E20 batch: procedures stated
as ordinary prose fell outside the trigger/response subset `src/skill_compiler.rs`
recognizes, so `docs/USER-JOURNEYS.md` F2 could only be scaffolded. PR
[#815](https://github.com/link-assistant/formal-ai/pull/815) adds
`src/skill_procedure.rs`, a seeded step vocabulary, and the solver wiring that
compiles, executes, restates, and honestly refuses such procedures.

| ID | Requirement | Status |
| --- | --- | --- |
| R550 | Compile a freely phrased multi-step procedure that matches no existing compiler template into an ordered, typed, executable program. | `compile_procedure_with_ledger` in `src/skill_procedure.rs` calls the public intent formalizer, decomposes the impulse through shared `ordered_requirement_spans`, maps each source-grounded requirement onto a typed operation, and requires both a trigger lead and at least two recognized steps; covered by `arbitrary_four_step_procedure_compiles_executes_and_restates_its_steps` and `compiler_reuses_intent_formalization_and_records_every_ordered_requirement`. |
| R551 | Grow the step vocabulary as data rather than Rust parser match arms. | Seed meanings live in `data/seed/meanings-skill-procedure.lino`; reviewed multilingual aliases live in the append-only `data/meta/procedure-capability-ledger.lino`. Both feed the same classifier. Learned aliases may target only an operation with existing typed host semantics, so classification grows without generated parser branches or silently invented side effects. |
| R552 | Compile the same procedure in English, Russian, Hindi, and Chinese to the same skill links. | `CompiledProcedure::links_notation` and `link_records` project canonical slugs only, and the content-addressed id is derived from that slug-only program; covered by `same_procedure_in_every_supported_language_compiles_to_the_same_skill_links`. |
| R553 | Fail honestly with a named gap on an uncompilable step, record a `skill_gap` event, and compile nothing partially. | `ProcedureCompileError::UncompilableStep` carries the clause, its span, and `no compiled capability for "…"`; `src/solver_handlers/procedure_rules.rs` records both the gap and complete review-only proposal artifact, and emits no compiled prefix. Covered by `uncompilable_step_reports_a_named_gap_and_compiles_nothing_partially`, `solver_answers_an_uncompilable_step_with_the_gap_and_a_skill_gap_event`, and `solver_records_a_learning_proposal_but_still_compiles_nothing_on_a_gap`. |
| R554 | Keep compiled skills inspectable: *"why did you do that?"* cites the compiled steps and their source sentence spans. | Requirements and steps retain exact source text and UTF-8 byte spans. The solver persists the complete artifact in its assistant reply; `meta_explanation` parses and integrity-checks that artifact instead of recompiling a prior user turn. Covered by `solver_compiles_a_freely_phrased_procedure_and_can_restate_it_later` and `compiled_artifact_round_trips_executes_and_explains_without_recompiling_user_prose`. |
| R555 | Persist a complete program that can be parsed and executed independently of the original compiler call. | `artifact_links_notation` serializes the formalized impulse, requirements, provenance, canonical program, trigger, and steps; `from_artifact_links_notation` recomputes ids/program and validates spans before `ProcedureHost` walks it. The round-trip test also rejects a tampered content id. |
| R556 | Feed named gaps into automatic learning without letting automatic learning authorize behavior. | Each gap deterministically creates a `ProcedureLearningProposal`. Given observed unsupported surfaces plus successful seeded paraphrases, `infer_candidate` derives the canonical typed operation itself and rejects conflicting meanings. `ProcedureCapabilityLedger::promote_candidate` then requires en/ru/hi/zh parity, a green named regression suite, and explicit non-empty human approval while preserving the inference evidence and content-addressed candidate id. Failure, tamper, promotion, and restart paths are covered by `named_gap_proposes_human_gated_learning_and_an_approved_lesson_generalizes`. |
| R557 | Execute the same task through Formal AI's Agent path and preserve exact evidence. | `src/agentic_coding/procedure.rs` routes the shared compiled artifact through write, read-back verification, `formal-ai procedure conformance`, execution-result verification, and final response. `agentic_planner_writes_verifies_and_returns_the_same_compiled_artifact` and `public_cli_executes_the_persisted_artifact_with_the_same_interpreter` check the in-repo/public paths; `experiments/issue-674-agent-cli/run.sh` drives the external Agent CLI, byte-compares the artifact, and requires the conformance command in its preserved stream. |
| R558 | Verify the ambitious requirement set both leaf-by-leaf and as one task. | `cargo test --test unit arbitrary_skill_compilation` contains focused decomposition, canonicalization, failure, artifact, learning, and Agent tests plus `whole_task_uses_one_artifact_across_solver_interpreter_explanation_and_agent`, which carries one artifact across the solver, parser/interpreter, later explanation, and Agent planner. |
