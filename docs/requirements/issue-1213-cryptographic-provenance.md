### Integration boundary clarifications

Commit ordering must avoid self-reference: a precommit anchored chain prefix supplies the trailer; a detached postcommit observation/seal binds actual commit, tree, parents and that anchor. Verify the anchored prefix separately from the complete detached chain/seal and detect truncation against a trusted expected head; no tree contains its own identifier. Explicit snapshot coverage/exclusions omit self-evidence destinations without crediting foreign/unlogged blobs. Reverify after amend, rebase and squash. Hive Mind demanded-attribution mode fails closed before PR-ready/authorship claims; ordinary release capability targets remain separately report-only. External Hive Mind integration remains pending until deployed and exercised. Canonical typed encoding specifies UTF-8 byte key order, exact bytes/base64, integers beyond 2^53, numeric/string distinction, Unicode/newlines, duplicate-key refusal, finite-float/-0 policy and canonical reserialization; include prev, session/domain and sequence, exclude only the own hash field. Capture nondeterministic time/environment for replay. Current EventLog identifiers are FNV1a64, not cryptographic; existing source transaction SHA256 is not BLAKE3. Chain records contain actual Formal AI published thinking/EventLog and derivation only. Authoritative memory custody must cover replacements, atomic rewrites, external changes and concurrent writers using revision/byte checks and a real lock; an incremental append assumption is insufficient.

Replay must actually rerun the pinned engine from captured inputs and genesis memory. SHA256 event consistency is not computation replay; unsupported or failed replay is never verified.
