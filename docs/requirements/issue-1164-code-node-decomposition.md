## Issue #1164 Code Node Decomposition

Issue [#1164](https://github.com/link-assistant/formal-ai/issues/1164) (E129,
part of the #1183 umbrella) makes retrieved code examples formal knowledge: an
example is parsed into the meta language, decomposed into meaningful parts
(entry point, output operation, string literal, import, build and run
commands), generalized across languages by aligning those parts, and
recomposed for a new requirement. The issue states `R1164-1` to `R1164-11`;
`R1164-12` to `R1164-15` are the further obligations of its "Tests" and
"Definition of done" sections. The timeline, root causes and prior art live in
`docs/case-studies/issue-1164/`.

The module is `rust/src/code_example_knowledge.rs`, not the
`rust/src/coding/code_node_decomposer.rs` the issue names; the two test
modules the issue sketches are consolidated in
`rust/tests/unit/issue_1164_code_example_knowledge.rs`. The part vocabulary
and the per-language program shapes are data in
`data/seed/code-example-parts.lino`.
