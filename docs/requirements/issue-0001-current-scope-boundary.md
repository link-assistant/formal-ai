## Current Scope Boundary

This PR is a deterministic symbolic implementation, not a full universal problem solver. The implemented core proves that the repository can expose OpenAI-shaped interfaces while returning symbolic, inspectable, Links Notation-backed answers and reviewable seed datasets. Full imports of very large corpora such as Wikipedia, Wikidata, Rosetta Code, Wikifunctions, and hive-mind history should run as chunked follow-up dataset jobs behind the same `.lino` format and 1500-line file limit.
