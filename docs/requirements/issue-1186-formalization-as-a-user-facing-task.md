## Issue #1186 Formalization as a User-Facing Task

Issue [#1186](https://github.com/link-assistant/formal-ai/issues/1186) (E150,
part of the E127 umbrella #1183): "Formalize in first-order logic: Every
student who studies passes the exam." answered with the canned web-search
paragraph on 0.347.0. The issue asks for a formalization handler that parses
a quantified sentence into a clause, renders it into first-order logic, Lean
and Rocq, deformalizes it back in en/ru/hi/zh with a structural round trip,
and does so identically in all three roots without memorizing any probe.
R1186-1 through R1186-9 are the issue's R1–R9; R1186-10 is the per-language
probe set its "Probe set and tests" section specifies. The audit and the
fix history live in `docs/case-studies/issue-1186/`.

| ID | Requirement | Status / Evidence |

| R1186-1 | A prompt carrying a formalization command ("formalize", "формализуй", "औपचारिक बनाओ", "形式化") routes to the formalization handler before the search fallback and never yields the canned "Web search requested" paragraph. | Implemented: the `cues` record of `data/seed/formal-targets.lino` declares the command surfaces per language (es too), and `rust/src/solver_dispatch.rs` places `formalization_request` immediately before `product_search` and `web_search`.
