## Issue #1173 No Canned Search Answer in the Unknown-Reasoning Fallback

Issue [#1173](https://github.com/link-assistant/formal-ai/issues/1173) (E138)
deletes the descriptive "Web search requested for `…`" paragraph as an answer
surface and makes the unknown-reasoning fallback execute its web search. The
source analysis, the deleted answer arms, and the evidence live in
`docs/case-studies/issue-1173/`.
