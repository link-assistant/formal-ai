## Issue #703 External-Agent Orchestration

Issue [#703](https://github.com/link-assistant/formal-ai/issues/703) and the
maintainer follow-up on PR
[#876](https://github.com/link-assistant/formal-ai/pull/876#issuecomment-5127332907)
require Formal AI to become the explicit controller of external agents:
registered and requested custom clients, bounded workspaces, parallel
comparison and composition, replayable evidence, exact-session correction,
meta-language synthesis, requested-language output, fact cross-checking, and
learning from completed work. The implementation keeps execution,
fact-verification, translation, and learning grants visible rather than
conflating model confidence with authority.

| ID | Requirement | Status |
| --- | --- | --- |
| R703-1 | External agents must be denied by default and receive only an explicit canonical workspace, hard timeout, captured output/effects, and reviewable provenance. | `AgentRunPermission`, `workspace`, `runner`, and canonical hash-chained `AgentSession` records implement the boundary; timeout kills the Unix process group and records one failed attempt. Covered by permission, containment, timeout, no-retry, effect, and replay tests in `rust/tests/integration/issue_703_orchestration.rs`. |
| R703-2 | Drive Agent CLI, Claude Code, Codex, Gemini CLI, Qwen Code, and OpenCode from a data-defined adapter registry, against loopback Formal AI or existing vendor authentication. | Implemented: `data/seed/client-integrations.lino` carries editing, structured-output, and resume argv; `AgentTarget::{FormalAi,Vendor}` selects the target. The deterministic six-entrypoint test drives the public CLI; the real-client matrix is opt-in because it needs each vendor's own authentication. Pinned by `rust/tests/integration/issue_703_orchestration.rs` (`all_six_cli_entrypoints_run_a_scripted_repo_task_through_the_real_wrapper`, `seed_registry_pins_each_clients_exact_native_resume_contract`, `all_required_seed_adapters_capture_process_and_workspace_events`, `direct_vendor_entrypoints_keep_editing_and_prompt_arguments`). |
| R703-3 | Decompose a task into bounded leaves, dispatch them, verify their work, and compose only passing non-conflicting effects. | Implemented: `orchestration::dispatch` uses the universal task decomposer, isolated copies, argv-based executable-allowlisted verification, drift revalidation, conflict detection, and transactional composition. Pinned by `rust/tests/integration/issue_703_orchestration_followup.rs` (`universal_decomposition_dispatches_independent_leaves_in_parallel`, `decomposition_never_composes_changes_from_a_failed_agent`, `verification_commands_must_be_explicitly_allowlisted`, `comparison_refuses_to_overwrite_workspace_drift_after_candidates_fork`) and `rust/tests/integration/issue_703_controller_boundaries.rs` (`leaves_writing_different_bytes_to_one_path_are_refused_by_name`). |
| R703-4 | Run the same task through several agents in parallel and choose a passing result by a deterministic recorded rule. | Implemented: `DispatchMode::Compare` emits canonical candidate sessions and `comparison-ledger.json`, ordering by passing status, diff size, wall time, CLI id, then session path. Pinned by `rust/tests/integration/issue_703_orchestration_followup.rs` (`parallel_comparison_records_a_ledger_and_composes_the_winner`, `winner_selection_is_deterministic_for_a_recorded_ledger`, `committed_parallel_comparison_ledger_records_the_selected_winner`, `dispatch_joins_every_worker_before_returning_an_error`) and `rust/tests/integration/issue_703_orchestration.rs` (`comparison_cli_succeeds_when_one_verified_winner_passes`). |
| R703-5 | Explicitly control a requested custom CLI/TUI entrypoint, Bash adapter, local model frontend, or other neural client, including several custom agents. | Implemented: `agent run --command JSON_ARGV` and repeated dispatch `--command CLI=JSON_ARGV` mappings require `{task}` and an independent exact `--allow-agent-command` grant. Unknown executables, an argv without `{task}`, and registered-label grant bypasses are rejected; public single/multi Bash regressions prove the surface. Pinned by `rust/tests/integration/issue_703_orchestration.rs` (`public_cli_runs_an_explicitly_granted_agent_through_bash`, `public_cli_compares_multiple_explicitly_granted_bash_agents`, `arbitrary_agent_program_requires_a_separate_explicit_grant`, `a_registered_cli_label_does_not_bypass_the_custom_program_grant`) and `rust/tests/integration/issue_703_controller_boundaries.rs` (`a_custom_entrypoint_without_a_task_placeholder_is_refused_before_it_runs`). |
| R703-6 | Preserve each client's native conversation and resume that exact session with feedback when a claim is disproved. | Implemented: sessions record `NativeAgentSession`; `agent resume` binds `CorrectionRequest` to the canonical parent digest, inherits the original client/target/model/base URL, renders multilingual feedback from seed data, and records `AgentContinuation`. A changed reported id fails. All six resume argv contracts and the real Agent CLI `--resume ID --no-fork` chain are byte-pinned. Pinned by `rust/tests/integration/issue_703_orchestration_followup.rs` (`a_proven_false_claim_resumes_the_same_native_session_with_parent_evidence`, `continuation_rejects_a_client_that_reports_a_different_native_session`, `real_formal_ai_correction_chain_resumes_one_native_session_and_pins_the_artifact`, `cross_agent_correction_evidence_is_seeded_in_every_supported_language`) and `rust/tests/integration/issue_703_orchestration.rs` (`public_cli_resumes_the_recorded_vendor_session_with_correction_evidence`, `seed_registry_pins_each_clients_exact_native_resume_contract`). |
| R703-7 | Capture complete sessions and replay them byte-for-byte, detecting edits, truncation, reordering, or broken ancestry. | Implemented, JavaScript first: canonical pretty JSON, terminal newline, event sequence, previous-event links and event SHA-256 are checked on replay, and the session fields the events stand for are bound to them (one terminal outcome matching `status`, `workspace_effect` events equal to `changes`, a continuation exactly when a native session was resumed), so an edited event, an edited status or effect list, a dropped tail event, reordering and byte truncation are each rejected by name. `replay_continuation` replays a correction only against the exact parent bytes its digest names, so broken ancestry, including a parent whose free-text stdout was edited, is rejected. Free-text fields are bound by that parent digest and the committed bytes, not by the event chain. Pinned by `rust/tests/web/issue-0703-session-replay.test.mjs` (`js/agentic/crate/orchestration_replay.mjs`, every committed session) and `rust/tests/integration/issue_703_replay_tamper.rs` (`rust/src/orchestration/replay.rs`), plus `rust/tests/integration/issue_703_orchestration_followup.rs` (`recorded_session_replays_byte_for_byte`, `replay_rejects_valid_but_noncanonical_json`). |
| R703-8 | Formalize agent answers in the meta-language, summarize them, rank/recheck claims, report contradictions, and feed proven denials back as corrections. | Implemented: `orchestration::analysis` extracts only answer-bearing events, preserves complete streams in sessions, uses the production formalize/deduplicate/rank/recheck/summarize ladder, records meta-language per source, and emits evidence-linked `CorrectionRequest`s. Pinned by `rust/tests/integration/issue_703_orchestration_followup.rs` (`council_results_are_formalized_summarized_and_cross_checked`, `synthesis_extracts_the_final_answer_without_promoting_agent_diagnostics`). |
| R703-9 | Cross-check facts without presenting model agreement as external proof. | Implemented: every synthesis report labels `fact_check_scope` as `cross_agent_evidence_preflight`; unsupported/denied claims are withheld and contradictions retained. Documentation requires captured primary sources and the production fact-check path for external guarantees. Pinned by `rust/tests/integration/issue_703_orchestration_followup.rs` (`council_results_are_formalized_summarized_and_cross_checked`, `documentation_traces_the_maintainer_followup_without_overclaiming_fact_or_learning_gates`). |
| R703-10 | Return the result in requested `en`, `ru`, `hi`, or `zh`, without falsely labelling untranslated text. | Implemented: synthesis records target, detected final language, and `translation_required`. `apply_verified_translation` accepts only a separately recorded translator-agent result detected in the target language and retains its session digest; a wrong-language translation fails closed (`translation_language_mismatch:ru:en`). Pinned by `rust/tests/integration/issue_703_orchestration_followup.rs` (`council_results_are_formalized_summarized_and_cross_checked`, `public_cli_synthesizes_translates_and_proposes_learned_adapter_updates`) and `rust/tests/integration/issue_703_orchestration_languages.rs` (`vendor_orchestration_preserves_tasks_in_every_supported_language`). |
| R703-11 | Learn from completed orchestration while retaining review and promotion gates. | Implemented: `observe_orchestration_session` projects canonical evidence into the existing client-contract learner; `formal-ai agent learn` emits proposal-only Links Notation (`decision "awaiting_human_review"`). It cannot mutate the registry or approve promotion, consistent with the repository's human gate. Pinned by `rust/tests/integration/issue_703_orchestration_followup.rs` (`repeated_orchestration_sessions_feed_human_gated_adapter_learning`, `public_cli_synthesizes_translates_and_proposes_learned_adapter_updates`). |
| R703-12 | Prove the controller through Formal AI and the real Agent CLI, preserve failures honestly, and meet the self-authorship policy. | Implemented: `docs/case-studies/issue-703/` records the six-client matrix, original self-hosted leaf, and a three-turn same-native-session correction chain. Commit `70848eb3` carries `Formal-AI-Session` and `Formal-AI-Evidence` trailers; the focused suite pins every canonical byte, parent digest, resume argv, and final artifact hash. Pinned by `rust/tests/integration/issue_703_orchestration_followup.rs` (`formal_ai_authored_invariant_is_byte_pinned_to_its_session_evidence`, `real_formal_ai_controller_agent_run_replays_from_committed_bytes`, `real_formal_ai_correction_chain_resumes_one_native_session_and_pins_the_artifact`) and `rust/tests/web/issue-0703-session-replay.test.mjs` (the chain replays parent to child in JavaScript). |
