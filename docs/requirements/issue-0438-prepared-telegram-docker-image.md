## Issue #438 Prepared Telegram Docker Image

Issue [#438](https://github.com/link-assistant/formal-ai/issues/438) asks for a
fully prepared Docker image for the Telegram bot so the system can be started
with minimum configuration, ideally from a single shell line. PR
[#470](https://github.com/link-assistant/formal-ai/pull/470) turns the existing
Docker-in-Docker runtime into a release-published image and records the
operator path in docs and tests. The follow-up maintainer comment additionally
asks for one-click start/stop of both the Telegram bot container and the
OpenAI-compatible agentic server container from the desktop app, with the same
flow documented for server operators.

| ID | Requirement | Status |

| R320 | Issue #438 research, issue metadata, PR metadata, comments, CI context, related PRs, online research, and reproduce-before-fix logs must be preserved under `docs/case-studies/issue-438`. | Implemented by `docs/case-studies/issue-438/README.md` and `docs/case-studies/issue-438/raw-data/*`, including `repro-before-docker-runtime.txt`, `repro-before-release-workflow.txt`, and `repro-before-docs-traceability.txt`. |
