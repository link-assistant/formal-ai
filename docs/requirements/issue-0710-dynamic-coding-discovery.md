## Issue #710 Dynamic Coding Discovery Continuation

The 2026-09-14 continuation audited every coding and benchmark requirement,
removed benchmark-specific synthesis bodies, and connected structural task
recognition to licensed external parts, composition, bounded verification, and
rediscoverable procedure memory. The implementation plan and before-state
evidence live in `docs/case-studies/issue-710/plans/`.

| ID | Requirement | Status / Evidence |
| --- | --- | --- |
| R710-D1 | Coding synthesis must derive answers from task structure and sourced operations, never from upstream case names or copied task sentences. | Implemented by `task_spec`, `concept_discovery`, and `composition`; `coding_discovery::no_memorization` scans the downloaded HumanEval/MBPP slice against `src/` and `data/seed/`. |
| R710-D2 | The full HumanEval suite (164 cases) must be run honestly through the discovery path and report its upstream grading result, with the first-20 slice retained as a regression control. | Implemented by `benchmark run --suite humaneval --slice 164`, cold-offline and with `--online`; the committed 2026-09-17 full-slice row passes 14/164 upstream tests with `--online` (a cold-offline run in the same session scored 9/164), and the 2026-09-15 first-20 row — 20/20, with an empty-source-cache control — stays as the regression control. |
| R710-D3 | The full MBPP suite (500 cases) must be run honestly through the same discovery path and upstream assertions, with the first-20 slice retained as a regression control. | Implemented by `benchmark run --suite mbpp --slice 500`, cold-offline and with `--online`; the committed 2026-09-18 full-slice rows pass 49/500 cold-offline and 60/500 with `--online`, and the 2026-09-15 first-20 row — 20/20 `--online`, with a cold offline control at 18/20 naming the two externally defined sequence gaps — stays as the regression control. |
