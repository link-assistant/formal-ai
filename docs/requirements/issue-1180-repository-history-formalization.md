## Issue #1180 Repository History as Formal Context

Issue [#1180](https://github.com/link-assistant/formal-ai/issues/1180) (E145,
part of the E127 umbrella #1183) asks for the repository's full history —
commits, issues, pull requests, comments, reviews and Actions runs — to be
formalized into records the solver can query, so lineage questions ("which
issue asked for X and which pull request delivered it") have an answer.
R1180-1 through R1180-8 are the issue's own numbered requirements; R1180-9
through R1180-11 are derived from its "What to build", "How to test" and
"Depends on" sections so that nothing the issue asks for goes untracked. The
timeline, root causes and verification live in
`docs/case-studies/issue-1180/`.

| R1180-1 | A commit importer walks `git log` on the working repository and formalizes each commit's author, committer date, subject, body, trailers (`Refs #NNN`, `Closes #NNN`, `Co-Authored-By:`) and changed paths into one record per commit. | Implemented: `rust/src/history_context/commits.rs` (`import_commits`, `formalize_commit`) records author role, committer date, subject plus body as content, every changed path as `path:` evidence, the `Refs`/`Closes` trailers as `issue:` evidence and the conversation id, and every `Co-Authored-By:` trailer (the seed's `coauthor_trailer` row in `data/seed/history-formalization.lino`, read by `coauthors` in `rust/src/history_context/items.rs`) as `coauthor:<name>` evidence. | R1180-2 | For every changed `.rs` path the importer runs `self_ast::ast_census` on the pre- and post-image blobs (`es_meta` for `.js`/`.ts`) and records which top-level items differ, not only which paths changed. | Implemented: `diff_symbols` reads both blobs with `git show` and, besides the census histogram delta, records each named top-level item that was added (+1), removed (-1) or modified (0) as `symbol:<path>#<keyword> <name>` evidence (`diff_named_items` in `rust/src/history_context/items.rs`). The names come from a line-level scan of the seed's keywords, not from the AST: an item opened inside a macro or on an indented line is not named. |
