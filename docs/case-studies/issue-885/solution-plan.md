# Issue 885 solution plan

## Root causes

1. Legal guidance existed only as one long policy. It did not give readers
   focused answers for symbolic/LLM boundaries, public-domain output, datasets,
   or current model candidates.
2. The statement auditor extracted each Markdown line independently. “It” and
   similar local references therefore lost their antecedent, exact evidence for
   the expanded claim could not match, and downstream confidence was unrelated
   to antecedent confidence.
3. Several philosophical statements mixed architecture, aspiration, metaphor,
   and mathematical claims. In particular, computational universality belongs
   to an adequate normal Markov algorithm, not to each isolated rewrite rule.

## Implemented sequence

1. Capture the linked-conversation metadata and current primary-source research.
2. Add failing tests for closest-reference resolution, resolved evidence,
   contextual probability, document isolation, and demonstrative determiners.
3. Add stable reference links and `resolved_text` to each audited statement.
4. Compute `contextual_posterior` as the evidence posterior bounded by the
   referenced antecedent and persist the dependency in JSON and Links Notation.
5. Add separate, dated legal guides and fail-closed dataset/model matrices.
6. Add the fact-checked philosophy and link it from the project vision.
7. Execute one of five smallest documentation leaves through Formal AI and the
   real Agent CLI; retain the exact generated bytes and session logs.
8. Run the focused regressions, repository statement audit, local CI suite, and
   fresh GitHub Actions checks.

## Boundaries

- Closest-reference resolution is deterministic and document-local. It is not a
  claim of complete coreference understanding.
- The source matrices are candidates, not approvals. The training registry
  remains empty.
- Repository audit checks references, supplied evidence, contradictions, and
  relative probability. Human/legal review is still required for truth claims
  that cannot be established from repository or captured primary evidence.
- No hosted output or dataset payload is committed by this case study.
