## Required implementation and acceptance rules

1. **General strategies, not memorized answers.** Formalize requests and discover reusable procedures and source knowledge. Keep exact answers, task-name dispatch tables, seeded complete programs and supplied patches out of the claimed general solution. Rank plausible/simple/provable candidates after correctness and completeness; failures guide the next candidate and remain evidence.
2. **True cold start and rebuildable cache.** Delete learned procedures, page networks and resolved-version caches in an isolated hosted environment. Starting from only the declared minimal bootstrap, discover and verify the original Kotlin/Scala/Rust tasks and held-out languages/literals from real fetched pages. Repeat warm and deleted-cache runs, and separately test corrupt/stale cache and unavailable network. Record URL, response hash/time, licence/trust, exact input/output and budgets. A fixture-only transport or shipped whole-program baseline cannot pass the cold-network requirement.
3. **Strict implementation deduplication.** AST-based coverage includes named functions, closures/arrows, methods, same-file copies and large bodies across Rust/JS/TS. Equivalent implementations must have one canonical shared meta definition or an adopted maintained dependency. No arbitrary baseline, size ceiling, suppression, renamed copy or silently exempt generated clone can authorize duplicates. Reproducible translated outputs require source-definition identity and regeneration checks; this declared projection relationship must be verified, not treated as independent hand-maintained implementations. Negative controls add a same-file method, closure, cross-file renamed body and body over22 lines; each must fail until genuinely consolidated. Formatting, comments, identifier renaming and nesting must not defeat the check. Shared parser adoption requires exhaustive existing-data conformance and upstream resolution of real dialect gaps before deleting local parsers.
4. **Full capability and behavioral parity.** Inventory every public CLI/server/browser/agent capability and all three implementations, including unsupported routes and host-required effects. Test identical formal inputs, answer meaning, derivation, side effects, failures and terminal state in JS/TS/Rust. Source hashes, translated file existence, matching route names and finite happy-path pins alone do not establish parity. An unsupported inventory entry stays a visible unmet obligation until implemented and exercised; never silently omit it from a denominator. Prefer canonical meta definitions with JavaScript-first execution and reproducible TS/Rust projections. Rust/native/WASM/product compilation and execution occur only in hosted CI; local checks remain bounded source/JavaScript work.
5. **Finite integration checks.** Run original regressions and held-out multilingual paraphrases for every changed capability, with independent acceptance oracles fixed before attempts. Re-run the complete generated task-class comparison, no-memorization, dependency-currency, strict dedup, regeneration and cross-runtime behavioral checks on the integrated source. Use the original #1183 template-removal/unseen-language/cache-deletion checks, #1162 three-client delivery and #1170 rung2 evidence as separate gates. A source test is not a live delivery pass. Unknown usage/cost/outcomes stay Unknown; supplied controller recipes receive zero autonomous-authorship credit.
6. **One PR, bulk delivery and release continuity.** Integrate all related lanes into this one branch/PR; resolve overlaps with exact pre/post identities. Push a coherent reviewed bulk batch, observe green checks on its exact head and merge only that qualified head. Do not split unfinished requirements into hidden follow-up PRs or mark children closed from documentation. Preserve functioning release publication while reporting capability targets honestly; after merge, independently verify the exact released source and public downloads. A prior-head green run or old release smoke does not qualify a new head.
