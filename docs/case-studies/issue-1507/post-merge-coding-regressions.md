# Post-merge coding verification recovery

## Requirements

1. A complete literal Create request changes only its declared target. Existing journal contracts remain tested through their applicable owner; a journal receipt cannot authorize an unrelated target write.
2. Completion requires an exact, fresh, target-bound observation after the write. Prefer a dedicated Read tool. When only a permitted shell tool is available, use framed readback that preserves Unicode, JSON text and edge whitespace through legacy shell envelopes. Unknown, failed, truncated, foreign or unbound receipts cannot certify completion.
3. Discharge every requested artifact through the common obligation ledger. A Read retains its actual tool identity and honestly absent process exit status. A shell observation retains its actual command and reported exit. Exact qualified readback of another owned target is read-only; arbitrary commands remain potential mutations.
4. A dependent edit may reuse an actual preceding qualified Read of the same target. Preserve the original call and receipt. Foreign intervening mutations require a new observation. Keep the repetition guard and its finite budget.
5. Give applicable specialized editing tools an opportunity before reporting a generic missing-capability gap. A Bash-only client still receives an explicit gap when it cannot perform the requested edit.
6. Literal source text, quoted examples and overwrite permission are not requested operations. Bind an edit or whole-file action to its actual instruction and destination spans. An unsupported edit must never become a guessed whole-file overwrite. Unquoted declared payloads remain data too.
7. Before a literal journal operation, bind the actual next call to the maintained current plan and stable workspace. Reject altered paths, content and request identities before effects; do not give Set-contents exclusive-Create semantics.
8. Keep source-policy checks inexpensive on pull requests: use the JavaScript hardcoded-language and literal-policy twins without compiling Rust. Retain full integration checks for main or explicit qualification.
9. Bound local Formal AI invocations externally. An event-loop timer cannot interrupt synchronous planning. After a timeout or missing trace, inspect actual owned effects before retrying; never assume no changes occurred.
