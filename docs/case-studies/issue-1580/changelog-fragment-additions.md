# Added fragments and exact Git paths

The current Rust pipeline template at `260ae6f826d6bff0cbfe2280098c287a4c09b3f4` already distinguishes source-change inventories from added fragments. Upstream [PR 191](https://github.com/link-foundation/rust-ai-driven-development-pipeline-template/pull/191) explains why byte-identical moves do not count but replacements do. The later [PR 238](https://github.com/link-foundation/rust-ai-driven-development-pipeline-template/pull/238) preserves those rename regressions during broader CI changes. No duplicate upstream report was opened.

Our JavaScript and Rust checkers previously filtered both decisions from one changed-name list. A source change plus an edited, deleted or byte-identically moved pending fragment incorrectly passed; nested archived fragments also counted. Newline-bearing paths were quoted by Git and misclassified by newline splitting. Sixteen physical Git scenarios across root and `rust/` layouts reproduced fourteen failures before the fix. Plain new additions were the two passing controls. Replacement scenarios failed the exact count assertion because deleted old fragments were counted too.

Both roots now use `--no-renames --name-only -z` for source changes and `--find-renames=100% --diff-filter=A --name-only -z` for additions. Exact rename matching compares object IDs rather than fetching bodies for similarity detection. The existing physical blobless-promisor tests confirm that this second query succeeds with absent bodies and an unavailable origin, while the old similarity query fails. Only direct Markdown children of the selected changelog directory count. The README itself remains excluded; a different fragment whose name ends in `README.md` is allowed.

NUL-delimited inventories preserve path whitespace, newlines and an initial BOM. Both implementations refuse invalid UTF-8, missing terminators and empty records. Displayed paths escape CR/LF to preserve log boundaries. After the fix all 28 JavaScript cases and all 162 default-branch policy tests pass; changed Rust source passes rustfmt. Native inline regressions are registered in the existing hosted script contract lane; native execution is still pending and no Rust build ran locally.

Run `node --test --test-concurrency=1 rust/tests/web/changelog-fragment-output.test.mjs` to reproduce. Before/after output, pre-fix sources, upstream sources, related PR snapshots and SHA-256 identities are retained in `experiments/issue-1580/evidence/checks/changelog-fragment-additions/`. This verifies this applicable template practice only; the complete eight-template practice comparison and independent authorship criterion remain unfinished.
