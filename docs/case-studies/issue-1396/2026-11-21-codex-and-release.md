## Sources and alternatives

The localized wikiHow parse and article endpoints returned HTTP 200 on November 21. The Wayback index returned HTTP 200 and listed capture `20241222160007`. The Chromium run forced the API to fail and served committed article content with the recorded canonical URL, so it reproduced archive handling independently of live replay limits. The capture transport remains available when a browser cannot read the archive. [wikiHow article](https://ru.wikihow.com/хорошо-покакать) · [Wayback index capture](evidence/wayback-availability-2026-11-21.json) · [MediaWiki parse API](https://www.mediawiki.org/wiki/API:Parsing_wikitext)

Codex has an opt-in setting for Default-mode structured prompts. The plain-text path works with the default configuration and keeps the structured tool available when the descriptor supports it or the latest developer context explicitly identifies Plan mode. Upstream could align the advertised schemas with the runtime using the predicate that already guards execution. [Codex tool specification](https://github.com/openai/codex/blob/rust-v0.171.0/codex-rs/core/src/tools/handlers/request_user_input_spec.rs) · [Collaboration-mode context](https://github.com/openai/codex/blob/rust-v0.171.0/codex-rs/core/src/context/world_state/collaboration_mode.rs) · [Upstream discussion](https://github.com/openai/codex/issues/24750)

Marking all diagnostic steps `continue-on-error` would hide useful status. The release caller instead removes their dependencies and keeps the existing status job. Cargo's package check validates the source archive, while the staged publisher independently owns the binary and its runtime smoke tests. A successful workflow-projection replay establishes admission behavior. It cannot establish publication receipts. ## Reproduction

Start the source JavaScript server and send `Как какать?` via Responses with `tools: [{"type":"web_search"}]`. A relevant localized capture should contribute ordered steps with a source link. The regression uses a committed copy of the API body so it can distinguish an answer from a search call without network variance.

```sh
node --test --test-concurrency=1 rust/tests/web/issue-1396-native.test.mjs
SCENARIO=report SERVER=js CODEX_BIN="$(command -v codex)" bash experiments/issue_859_codex_e2e/run.sh
node --test --test-concurrency=1 rust/tests/web/default-branch-build-policy.test.mjs
```
