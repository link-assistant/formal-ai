## Research and alternatives

The personal-need route keeps the immediate NHS-backed advice from PR #1437. NHS guidance covers urgency and difficulty controlling bowel movements, and NIDDK guidance distinguishes constipation management from an immediate urge. The general procedure route continues to answer from sources for the actual task, so adding phrases to the practical registry is only needed to teach a distinct context-sensitive need. [NHS bowel incontinence](https://www.nhs.uk/conditions/bowel-incontinence/) · [NIDDK constipation treatment](https://www.niddk.nih.gov/health-information/digestive-diseases/constipation/treatment)

The MediaWiki parse API offers an existing structured transport for the live Russian article and avoids an extra network service on its successful path. For archive recovery, Internet Archive provides an index for the closest capture. Its replay returned `429` from this environment, so a deterministic replay fixture supplies matching HTML for the browser verification. The live archive coverage here is the availability response. [wikiHow article](https://ru.wikihow.com/хорошо-покакать) · [Wayback API](https://archive.org/help/wayback_api.php) · [Recorded index response](evidence/wayback-availability.json)

The existing `web-capture` integration can transport a page when direct browser access fails. It does not establish whether that page answers the task. Formal AI keeps the relevance decision, capture hashes, and settings at the call site. A hosted scraping or search service would add a new dependency and send the task to another provider. The existing WikiBooks and Stack Exchange discovery paths remain available according to their registry entries. [Upstream transport contract](https://github.com/link-assistant/web-capture/issues/147)

The reproducible defects were in Formal AI's classification, localized URL binding, evidence selection, and follow-up dispatch. The observed CORS difference and archive rate limit are service behavior. The capture component already has a tracked transport and receipt contract in #147. The investigation did not establish a separate reproducible library defect to report upstream.
