## Root causes

The latest default-branch pipeline had no failed or hanging test. Its Intel macOS job was still producing passing specification results when GitHub killed it at the unchanged 35-minute limit. The last successful instance already took 28m37s, so cold build time plus the growing monolithic suite had exhausted the remaining margin.

The wider audit also found a cancellation-scope defect: read checks and write jobs shared workflow-level concurrency. A newer run could interrupt an active writer, and GitHub's default one-pending-run behavior could replace an older queued writer. Job-level concurrency now matches side-effect boundaries.

A fresh link run found one real 502 and 18 healthy redirects. The copied template helper parsed every Markdown bullet across both sections and announced 19 broken URLs. It now parses only Lychee's error section (with a compatibility fallback), covered by a red/green Node regression; the unavailable source was replaced rather than ignored or excused by its archive.

The complete root-cause analysis and all nine issue requirements are mapped in the [durable evidence report](https://github.com/link-assistant/formal-ai/blob/issue-999-31976d2c6ce9/dev/log/issues/999/pulls/1000/README.md).
