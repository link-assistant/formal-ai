### Fixed
- Every phrasing of a desktop lookup now routes to the same local search. "Find X on my desktop", "Search X on my desktop" and "Find X folder on desktop" previously took three different routes; the last two went to the web (#842, #838).
- The local-search command no longer stops at the first hit (`find … -print` instead of `find … -print -quit`), so an answer can report every match instead of one.
- A bare "что это такое" with no prior turn is answered as an unresolved reference instead of with the capability menu, and a bare "ФБС vs ФБО" is answered instead of refused (#842, #826, #827).
- Russian definition requests ("дай определение слова X") are recognised as concept lookups.

### Added
- The issue #840 task ladder now judges refusals, capability-menu answers, tool misroutes and forbidden shell-command fragments — not just substrings — and answers `websearch` from an offline fixture corpus so the #827 nodes measure synthesis rather than routing.
- A `task-ladder` CI job runs the ladder on every code change, records the score in the run summary and fails when it drops below the recorded baseline. Measured 16/24, up from 8/24.
